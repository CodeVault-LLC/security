# Support policy

Before the first public release, the default branch is the only supported version. After release, the latest stable release and the default branch receive security fixes unless release notes state a longer period.

Use GitHub issues for reproducible product defects that contain no sensitive information. Use GitHub discussions for usage questions and design proposals when discussions are enabled.

Do not put suspected vulnerabilities, unpublished research, credentials, customer data, or proof-of-concept material in public support channels. Use the private reporting route in `SECURITY.md`.

Self-host operators own the host, network, TLS endpoint, identity provider, secret store, backups, monitoring, and incident response. The supported production baseline is documented in [Self-host CodeVault in production](docs/operations/self-hosted-production.md).
